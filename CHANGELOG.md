# Changelog

## 0.0.1

- Initial release.
- Compact monetary amounts using k, M, B and T.
- Optional currency metadata and opt-in financial rounding (disabled by default).
- Half-to-even rounding and automatic unit promotion.
- Symmetric negative amount support and normalized zero.
- Exact unit selection without rounding, with an optional decimal-place limit.
- Explicit decimal-place control for half-to-even rounding.
